# Repository work instructions

Before starting any task in this repository, read [`docs/WORKING-MANUAL.md`](docs/WORKING-MANUAL.md) in full. Treat it as the project operating manual and follow its task workflow.

When changing behavior or project decisions, update the relevant source-of-truth document in the same change. If the manual's workflow or current project state changes, update the manual and this file as needed. Never put API keys, secrets, passwords, or account identifiers in tracked files, chat messages, or logs.
