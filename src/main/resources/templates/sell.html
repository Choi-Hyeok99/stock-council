내가 확인하고 결정하는 매도

팔면 얼마가 남을까요?

보유 종목의 비용 후 손익을 보고, 수량을 정한 뒤 직접 모의 매도할 수 있어요.

계좌 확인 중

매도 전 확인

금액 확인 → 수량·손익 검토 → 내가 최종 전송 → 증권사 접수·체결 확인 순서예요. AI 투표 없이 직접 결정할 수 있어요.

기존 +5% 기준은 일부 익절을 검토하는 참고 기준이에요. 자동으로 매도하지 않아요. 지정가 주문은 미체결·부분 체결될 수 있고, 실제 체결·정산 금액은 달라질 수 있어요. 직접 매도 주문의 미체결 잔량은 보유·주문 화면에서 직접 취소해 주세요. 자동 취소하지 않으며 당일 지정가는 거래소·증권사 정책에 따라 만료될 수 있어요.

거래세 안내: 한국투자증권 공식 세금 안내 ↗

주문 처리 시간

최종 확인 → 전송 시작 목표 3초. 초과하면 전송 전에 중단해요. 증권사 응답·체결 시간은 별도이며, 기존 주문을 자동 재전송하지 않아요.

매도 금액 확인

매도 후 들어올 예상 금액매수·매도 비용 후 예상 손익

매수 수수료는 이미 낸 비용이에요. 이번 입금액에서 다시 빼지 않고, 순손익 계산에만 반영해요. 표시는 원 단위로 반올림해요.
