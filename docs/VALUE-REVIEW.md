# 기업 연구 기준

AI 분석은 투자 판단을 돕는 근거를 제공한다. AI는 주문·목표 수익·확정 상승 예측을 제공하지 않는다. 직접 모의 매도는 별도 사용자 확인 화면에서 요청한다.

## 8개 역할의 공통 질문

- 경제/정책: 실제 발표 시점·시행 여부·기업에 전달되는 경로는 무엇인가?
- 뉴스: 제목만 읽었는가, 본문을 확인했는가? 정정·중복·관련성이 확인됐는가?
- 산업/기술: 수요·고객·경쟁·기술 성숙도가 실제 매출/현금으로 이어지는 근거는 무엇인가?
- 재무: 기간·단위·연결/별도·일회성 이익·부채·현금 전환을 확인했는가?
- 시장: 미래 가정 대비 가격이 매력적인가? 하락과 가치 훼손을 혼동하지 않았는가?
- 위험: 가장 강한 반대 가설과 판단을 바꿀 관측 조건은 무엇인가?

자료가 없는 분야는 없는 이유와 필요한 원문을 적는다. 다른 역할의 검증을 모두 반복하지 않으며 자기 분야의 실제 근거로 조건부 의견을 낸다. 질문에는 실제 상대 발언으로 답한다. 토론을 위해 찬성이나 극적 싸움을 강요하지 않는다.

## 숫자의 의미

영업이익률=영업이익/매출, 부채비율=부채/자본, 영업현금흐름률=영업현금/매출, 현금전환=영업현금/양수 순이익. 비율은×100이다. 분모0 이하 또는 입력 누락이면 계산하지 않는다. 음수 분자는 그대로 둔다. 금융업은 제조업 비율로 건전성을 확정하지 않는다.

영업현금−유형자산 취득 절댓값−무형자산 취득 절댓값은 세 항목이 모두 있을 때의 부분 현금 지표다. 전체 투자활동·기업의 확정 FCF가 아니다. 전년 매출 성장은 같은 연결/별도·연속 연도만 비교한다. 연간과 중간 누계를 섞지 않는다.

PER/PBR/PSR과3년 평균이익 배수는 가격 참고 자료다. 적자·일회성·희석·주식 수 변경·우선주 청구권·업종 차이를 함께 확인한다. 업종 비교 자료가 없으면 평균값을 만들지 않는다.

## 미래성·저평가

1~3년 전망·경쟁우위·성장 경로·현금 창출을 살핀다. 과거 현금 수치가 있다고 미래가 확정되는 것은 아니며 미래를 확정 검증해야만 의견을 낼 수 있는 것도 아니다. 사실·가정·재판단 조건을 구분한다.

20일선 하회나 하락 자체는 거절 이유가 아니다. 낮은 가격/배수와 실제 저평가는 다르다. 일시적 하락일 가능성과 사업 훼손·가치 함정을 반문하고 가치 시나리오의 민감도를 보여준다. 상승 추세만으로 찬성하지 않는다.

최종6/8 찬성과 관심 분류는 논거에 대한 모델 의견이다. 수익 확률·전문가 보증·실제 투자 지시가 아니다. 규칙/입력 개선은 모델 재학습이나 강화학습이 아니다. 동일 공급자 모델의8개 역할을8개 독립 기관으로 취급하지 않는다.

## V7 근거 범위 보완

사업보고서와 최신 중간 공시의 기업코드·접수번호를 확인한 뒤 사업/영업/건전성/감사/위험/기술 구간을 제한 발췌한다. 수동 작성된 기업 설명이 없는 회사도 실제 본문을 전달한다. 전체 공시·감사·표 숫자 검증 완료로 취급하지 않는다. 원문의 단위·열·기간이 발췌 범위에서 확인되지 않으면 그 값은 미확인으로 남긴다. 공식 링크만 있는 상태와 실제 발췌를 구분한다.

기업별 공시는 최근30일 최대100건을 2분마다2개 기업씩 순환 수집한다. 시장 전체 최신200건의 공백을 보완하지만 전 기업/전 공시 포괄 수집은 아니다. 최근 제목 후보100건에서 일반 기업/기사 최대5건과 발행 관련 제목 최대1건을 고른다. 정정/철회는 발행 공시 제한으로 숨기지 않는다. 발행실적보고서·투자설명서를 실적 개선 호재로 해석하지 않는다. 기사 본문은 여전히 연결 전이다.

`roleCoverage`는 직접 근거 있음/일부만 있음/직접 근거 부족을 기록한다. 입력 개수나 수집 성공을 내용 검증/정확도로 표현하지 않는다. 기술 역할은 회사 사업에 맞는 기술·서비스 운영 역량을 평가하며 증권사에 임상/특허를 일괄 요구하지 않는다. 다른 역할의 재무 지표 부족을 모든 표의 자동 기권 사유로 복제하지 않는다. 관련 사건 부재, 분야 적용 한계, 실제 수집 누락을 구분한다. 핵심 근거가 부족하면 기권을 유지하며 최종6/8 기준은 바꾸지 않는다.

연간 `quantitativeFacts`와 중간 누계 `interimFacts`를 분리 계산한다. 모든 수치는 해당 기간·연결/별도 기준과 함께 읽는다. 본문 발췌의 반기 표와 연간 재무 비율을 혼용하지 않는다. 출처ID는 구조화 배열에만 넣어 짧은 설명이 해시 문자열로 잘리지 않게 한다. 출처 매핑은 서버가 검증한다. 이는 모든 숫자 해석의 자동 검증을 보장하지 않는다.

V7은 새로 고정된 자료에서 사용자가 직접 시작하는 회의에만 적용한다. 이전 의견/표/요약/비용은 원본 그대로 보존한다. 기존 분석을 자동 재호출하지 않는다. 같은 모델·최대25호출·24KB 입력·월$10 한도는 유지한다.

분석 입력에서는 긴 출처 해시를 회의별 짧은 별칭으로 전달한다. 서버는 허용된 별칭만 원본ID로 복원해 저장하므로 과거/현재 의견의 실제 출처를 유지한다. 출처 이름 단축은 근거 삭제나 검증 완화를 뜻하지 않는다. 최근 직접 검토한3개 기업은 상위10개에서 빠져도 자료를 갱신하며, 저장된 일봉을 재사용하면 당시 기준일과 갱신 대기를 표시한다.

## V8 근거를 사용하는 토론

각 역할은 고정 자료에서 뽑은 관측값·출처·계산 한계·상대 역할에 맞는 반문을 먼저 읽는다. 사실→매출/마진/현금/부채 영향 경로→반대 조건 순으로 설명하고, 확인된 인과관계와 가정을 구분한다. 다른 역할의 표에 동조하거나 관련 없는 자료 누락을 기권 사유로 복사하지 않는다. 정책/과학 등 직접 증거가 부족하면 판단 가능한 범위와 결정적인 미확인 항목을 특정한다.

RSS 제공 요약은 기사 전문·독립 교차검증과 구분한다. 공시 일부 발췌와 원 단위 계산은 전체 감사나 기술 검증을 대신하지 않는다. 산업별 경쟁사 수치·정책 원문/시행일·외부 기술 검증은 계속 수집 범위의 한계로 표시한다.
